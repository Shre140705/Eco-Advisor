# EcoAdvisor Phase 2 Data Dictionary

## 1. Scope

This dictionary defines the canonical fields for the initial EcoAdvisor catalogue and training data. It is the contract between the dataset, ML pipeline, database, API, and frontend.

## 2. Scale conventions

### Normalized suitability/sensitivity scale

For fields ending in `_score`, `_level`, `_sensitivity`, `_barrier`, `_compatibility`, `_strength`, `_resistance`, `_potential`, or `_circularity`:

- `0` = negligible, absent, or least favourable on that dimension.
- `50` = moderate/intermediate.
- `100` = very high, strongest, or most favourable on that dimension.

The direction must be stated in the field description. For burden fields such as relative cost, a high raw value means more burden; the decision engine inverts it when a benefit score is required.

### Provenance classes

- `LITERATURE`: traceable scientific publication or authoritative technical dataset.
- `STANDARD`: measurement, LCA, compostability, or technical standard.
- `REGULATORY`: food-contact or regulatory authority source.
- `ASSUMPTION`: explicit engineering assumption used where evidence is incomplete.
- `SYNTHETIC`: generated by a documented training-data generator.
- `USER_INPUT`: scenario-specific value supplied by the user.

### Confidence

- `HIGH`: directly supported by a traceable source under comparable conditions.
- `MEDIUM`: supported by a source but requires interpretation or has broader conditions.
- `LOW`: category-level or indirect evidence.
- `UNKNOWN`: not yet reviewed.

## 3. Food catalogue fields

| Field | Type/unit | Definition | Direction/interpretation | Evidence rule |
|---|---|---|---|---|
| `food_id` | string | Stable identifier `FOOD-###` | Identifier | Internal |
| `food_name` | string | Display name | N/A | Curated label |
| `food_category` | enum | Fruit, vegetable, dairy, bakery, processed, beverage, other | N/A | Curated classification |
| `freshness_state` | enum | Fresh or processed | N/A | User/catalogue |
| `physical_state` | enum | Solid, liquid, or semi-solid | N/A | Observable classification |
| `moisture_level` | 0–100 | Relative moisture level of the food | Higher = more moisture | Literature preferred; otherwise assumption |
| `fat_content` | 0–100 | Relative fat-content band for modelling | Higher = more fat | Literature preferred; unit must be recorded if measured |
| `ph_value` | pH 0–14 | Acidity measurement or band | Lower = more acidic | Literature or user input; do not infer exact pH from category |
| `perishability` | 0–100 | Relative tendency to deteriorate under stated conditions | Higher = more perishable | Literature/category assumption |
| `respiration_rate` | 0–100 | Relative respiration activity band | Higher = more active | Literature/category band; not a measured rate unless unit supplied |
| `ethylene_sensitivity` | 0–100 | Relative sensitivity to ethylene exposure | Higher = more sensitive | Literature preferred |
| `oxygen_sensitivity` | 0–100 | Relative sensitivity to oxygen exposure | Higher = more sensitive | Literature or documented assumption |
| `moisture_sensitivity` | 0–100 | Relative sensitivity to moisture gain/loss | Higher = more sensitive | Literature or documented assumption |
| `light_sensitivity` | 0–100 | Relative sensitivity to light-induced quality change | Higher = more sensitive | Literature or documented assumption |
| `default_temperature_c` | °C | Default storage temperature used when user does not override it | N/A | Source and storage mode required |
| `default_relative_humidity` | % RH | Default relative humidity | N/A | Source and storage mode required |
| `typical_shelf_life_days` | days | Reference shelf-life band/estimate | N/A | Never presented as model validation |
| `required_oxygen_barrier` | 0–100 | Barrier requirement derived from food sensitivity and intended use | Higher = stronger requirement | Derived, with derivation rule recorded |
| `required_moisture_barrier` | 0–100 | Required resistance to moisture transfer | Higher = stronger requirement | Derived/source-backed |
| `required_light_barrier` | 0–100 | Required light shielding | Higher = stronger requirement | Derived/source-backed |
| `mechanical_protection_required` | 0–100 | Required resistance to handling/transport damage | Higher = stronger requirement | Application assumption or study |
| `refrigeration_required` | boolean | Whether refrigeration is part of the default scenario | True/false | Storage source required |
| `data_status` | enum | Provenance class for the record | N/A | Mandatory |
| `source_ids` | array | Linked source records | N/A | Required for literature/regulatory values |
| `notes` | text | Caveats, scope, and conditions | N/A | Mandatory when assumption/synthetic |

## 8. Required cross-field validation

1. `ph_value` must be between 0 and 14.
2. All 0–100 scores must be within range.
3. `default_relative_humidity`, `relative_humidity`, and percentages must be 0–100.
4. Minimum temperature must not exceed maximum temperature.
5. `typical_shelf_life_days` and `shelf_life_days` must be positive when present.
6. A literature/regulatory record must have at least one source ID.
7. An assumption/synthetic record must contain a non-empty notes field.
8. A numerical OTR/WVTR value must include unit, measurement condition, source, and confidence.
9. `food_id`, `packaging_id`, and `source_id` must be unique.
10. Compatibility records must reference existing food and packaging IDs.
11. A `SYNTHETIC` training row must have `generator_version`.
12. A `carbon_footprint_score` must not be named or displayed as `kg_co2e` unless an absolute LCA value is separately stored with functional-unit metadata.
